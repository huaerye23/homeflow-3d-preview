# 栖居 · 全屋 3D 设计预览

基于两张户型参考图构建的 React + Three.js 交互式空间结构方案。模型完成层高固定为 **2.83m**，包含墙体门窗、过道动线、给排水、强弱电、空间聚焦、平面俯视和墙体剖切；家具软装不在表达范围内。

户型已按两张源图交叉对齐为北向朝上：北侧为主卫、北次卧、客卫、餐厨及景观阳台；南侧为主卧、南次卧、客厅和东次卧。过道只在主卧以东，主卧与主卫套内直通。北次卧按生活场景A并入原生活阳台西段，生活阳台仅留客卫北侧。面积按开间进深动态求和，玄关与客厅重叠不重复计：**112.7㎡室内 + 8.0㎡阳台 = 120.7㎡功能区净面积**。15.17m × 9.77m 的 **148.2㎡** 是套内矩形外包络；东侧电梯/楼梯公区进深至 10.76m，不作为套内或产权面积。

## 主要能力

- 3D 漫游 / 正交感平面俯视切换，支持拖拽、缩放和房间聚焦。
- 鼠标滚轮及界面 `− / 100% / +` 控件均可缩放；重置后仍可继续自由旋转和缩放。
- 14 个可点击功能分区（含过道），10 樘门按图纸洞口表达：入户对开、7 樘内门平开带开启弧线、生活阳台平开、景观阳台推拉门。餐客厅与厨房开放连通。
- 冷水、热水、排水三类管线及 13 个用水点位。
- 照明、插座、厨卫、空调等 5 组可视回路，35 个插座定位。
- 0.18–1.00 的墙体剖切控制，完整墙高为 2.83m；外墙/结构内墙 0.21m，隔墙 0.11m。
- 320px、375px 和桌面响应式界面，无横向溢出。
- 图纸依据弹窗可查看官方 4K 户型底图，以及西翼、中部、东翼关键区域。
- “导出方案”可下载当前房间/点位/图层状态 JSON。

## Image-to-code 交付

- `layers.manifest.json`：结构图、官方户型分析图、棠悦装修示意的尺寸、bbox、750px 预览与 4K 长边 3840。
- `public/references/`：官方 4K 底图、关键区域 4K 切片，以及 750px 预览。
- `qa/structural-plan-bbox-preview.png`、`qa/official-huxing-bbox-preview.png`：原图 bbox 框选复核。
- `qa/asset-audit.json`：参考位图尺寸审计。官方底图取自绿城玉海棠 142㎡ 户型页。

## 设计边界

官方底图改用房天下绿城玉海棠 142㎡ 户型分析图，关键西翼/中部/东翼已放大到长边 3840。结构尺寸仍以 CAD 模数 `3.49 + 0.21 + 2.79 + 0.22 + 5.27 + 0.21 + 2.98 = 15.17m` 与西侧进深 `5.17 + 0.22 + 2.87 + 1.51 = 9.77m` 为准；南侧卧室与北侧湿区之间按图纸表达 0.95m 过道。墙体性质、门窗洞口、给排水立管、配电容量和现场尺寸在施工前仍需复尺与专业校核。
